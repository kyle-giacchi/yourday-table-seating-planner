## [1.0.0] - 2026-04-16

Initial public release. YourDay is a 100% client-side visual room layout and seating planner.

### Features

- Drag-and-drop room setup with floor plan image upload and scale calibration.
- Table placement, rotation, and resize with snap-to-grid.
- Guest list management with party grouping and meal preferences.
- Seat assignment with drag-and-drop from party sidebar to seat dots.
- Banquet team summary view (prints per-table guest and meal counts).
- Config export/import (JSON) for backup and sharing.
- Color themes with HSL interpolation and edge glow.
- Zero backend — all data lives in `localStorage`.
